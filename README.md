# Multi-Branch Enterprise Network Configuration Using RIPv2

## Project Overview
Designed and simulated a multi-branch enterprise network connecting two office locations, Chennai and Bengaluru, using Cisco Packet Tracer and RIPv2 dynamic routing.

## Technologies and Concepts
- Cisco Packet Tracer
- Cisco Routers and Switches
- IPv4 Addressing
- LAN Configuration
- DHCP Configuration
- Router-to-Router Connectivity
- RIPv2 Dynamic Routing
- Network Connectivity Testing

## Network Design
The simulated enterprise network consists of two branches:

- Chennai Branch – 192.168.10.0/24
- Bengaluru Branch – 192.168.20.0/24
- Inter-Router Link – 10.0.0.0/30

## Implementation
1. Designed separate LAN networks for Chennai and Bengaluru branches.
2. Connected PCs to their respective switches and routers.
3. Configured router interfaces with appropriate IP addresses.
4. Configured DHCP for automatic IP allocation to end devices.
5. Established connectivity between the branch routers.
6. Configured RIPv2 for dynamic route exchange.
7. Verified routing information and tested communication between branches.

## Key Learning Outcomes
- Understanding multi-branch network architecture.
- Configuring IPv4 addressing and default gateways.
- Implementing DHCP.
- Understanding dynamic routing using RIPv2.
- Verifying routing tables and end-to-end connectivity.
